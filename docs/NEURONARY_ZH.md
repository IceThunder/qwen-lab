# 从 Neuronary 导入单条神经元配方

## 使用

```bash
cd qwen-lab
bash scripts/web.sh
```

打开 http://127.0.0.1:7860/，在左侧“模型与提示词”中展开 **从 Neuronary 导入配方**。即使当前选择 GGUF，也可以读取和预览配方。

1. 在 https://neuronary.org/ 打开一条配方，复制形如 `https://neuronary.org/r/y2r85pwz` 的链接。也可以仅粘贴 ID `y2r85pwz`。
2. 点击“读取配方”。检查网站模型、层号、通道、带正负号的 dose、兼容性和未应用的采样参数。
3. 选择网站中的一个示例提示词，或保留当前输入的问题。原帖干预／无干预回答可展开查看，它们只是参考，不会被写入本地对话。
4. “导入剂量倍率”默认 1，保留原 dose；若想先小剂量测试，可设为 0.1。例：−0.8 × 0.1 = −0.08。剂量保留正负号，不是激活乘法缩放。
5. 点击“导入配方与所选提示词”。这会切换到兼容的 MLX 基础模型、替换全部干预组、新建对话并展开神经元控制台。有旧会话、干预或草稿时会提示确认，可先导出保存。
6. 点击“发送并运行”，在同一提示词下比较本地无干预与干预结果。导入本身不执行推理。

不需要登录 Neuronary 或提供 token；导入只向固定公开 API 读取选中的配方，不上传本地提示词、对话或测试结果。

## 导入哪些内容

- 层号和神经元编号从 0 开始，映射为 `normalized_add`（归一化加法），不是乘法倍率。
- 默认原样使用网站 dose；只有用户设置导入倍率时才缩小剂量。单条配方可包含 1–32 个普通 MLP 通道。
- 应用网站 `sampling.temperature`（本地支持 0–1.5）。未提供或超范围则使用 0 并提示。
- 重复惩罚、top-p 等其他网站采样字段保留在预览和来源记录中，**当前不会应用**；有这些字段的配方不能视为严格复现。
- 本地导入约定：关闭思考、开启无干预对照、校准跳过首 token、使用基础模型而非 LoRA。界面明确展示这些设置；不会根据网站自由文本备注猜测参数。
- 默认勾选清空系统提示词和用户前后缀，减少原会话提示词对实验的影响；可以取消勾选。生成上限、上下文预算、种子保持现有设置。
- 来源 ID、链接、模型、原始通道、原采样参数、选中的原帖示例、导入倍率和本地校准约定保存在会话及每轮实验快照。手动修改通道后，来源仍标记为“初始配方”，当前参数以该轮快照为准。

## 当前支持范围

| 网站模型／类型 | 本地支持 |
|---|---|
| `Qwen/Qwen3.5-4B` 的普通 MLP 通道 | 可导入原有 `qwen3.5-4b` MLX 4-bit 模型 |
| HauhauCS 4B / 9B GGUF | 不支持这套激活干预，不会按名字或相同参数量自动匹配 |
| 其他模型、模型版本 | 可预览，未匹配兼容模型时禁用导入 |
| MoE expert 神经元、重复通道、越界编号、超出 ±4 的剂量 | 明确报错，不猜测、不截断 |

网站配方指定原始模型名称，但不一定指定权重提交和精度。本地使用社区转换的 4-bit 权重，无法承诺与作者输出相同。

本地校准为：完整提示词先无干预运行，取每层输出残差范数中位数（默认跳过首 token），除以相应 down_proj 权重列范数；随后对该轮所有输入和生成 token 注入固定偏移。网站描述给出了相同的归一化公式，但未完全规定校准输入、偶数中位数规则等实现细节。因此这属于明确记录实现约定的本地尝试，不应把单次结果称为精确复现。

如果出现重复，先降低导入倍率／dose，缩短生成预算并检查无干预对照。本功能没有新增自动防重复或自动降剂量机制。

## 文件与接口

- `web/neuronary.py`：链接校验、固定公开 API 读取、配方字段校验与兼容性转换。
- `POST /api/neuronary/preview`：请求体为 `{"url":"https://neuronary.org/r/y2r85pwz"}`，只返回预览，不修改模型或启动推理。
- `tests/test_neuronary.py`：来源链接、模型匹配、剂量、边界与外部读取约束测试。
- `tests/fixtures/neuronary_y2r85pwz.json`：公开示例快照，测试不依赖网站实时可用性。

目前仅支持 HTTPS 的 `neuronary.org/r/<ID>` 或 ID；不跟随外部重定向，读取超时 15 秒，响应最大 1 MB。网络失败、失效链接会提示错误，并保留当前实验设置。

参考：网站公开接口文档 https://neuronary.org/agents.md 。网站的描述、备注与示例作为数据展示，不执行任何远程代码。

## 更新后出现“读取失败：不存在的路径”

这通常表示页面已加载新版脚本，但 Python 后端仍是更新前启动的进程。只刷新网页不会加载新后端代码。先在启动终端按 Ctrl+C，再从项目目录运行 `bash scripts/web.sh`，随后刷新网页。重启会释放模型、清空服务器临时任务，但不会清除浏览器中已保存的对话。请先停止或等待正在运行的生成任务。
