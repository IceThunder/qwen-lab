# Qwen Lab：本地可视化神经元调试界面

快速上手：[中文启动、使用与停止指南](QUICKSTART_ZH.md)。

## 启动

```bash
cd qwen-lab
bash scripts/web.sh
```

在浏览器打开 **http://127.0.0.1:7860**。终端保持打开，按 `Ctrl+C` 停止服务。端口被占用时：

```bash
bash scripts/web.sh --port 7861
```

这是独立的 Web 界面及推理后端，**不需要同时启动 `scripts/serve.sh`**。首次安装需要执行 `bash scripts/setup.sh`。日常启动不需要 npm 或 Node.js。页面没有外部字体、脚本或 CDN；推理使用本地模型。运行训练、旧 API 或另一份模型进程前，先停止 Web 服务以释放内存。

服务只监听本机 `127.0.0.1`，没有开机启动。关闭网页不会停止 Python 后端，已加载的模型会保留在内存中，以便下一轮快速运行。

## 模型管理

顶部“模型管理”提供 Hugging Face 仓库读取、版本选择、进度、暂停续传和测试加载。完整文件校验后自动加入模型列表；不保证任意架构都能运行。详见 [模型管理说明](MODEL_MANAGER_ZH.md)。

## 界面布局

- **模型与提示词**：选择模型、LoRA 适配器、提示词模板，修改系统提示词、用户前缀和后缀，以及生成参数。
- **对话区**：多轮对话、流式输出、原始／干预对照、每轮配置快照、历史问题重跑。
- **神经元控制台**：点击层号添加干预组，填写通道编号、拖动倍率滑块，支持多个层和多个通道。

默认显示模型与对话两栏，神经元控制台隐藏。点击顶部“展开神经元控制台”可显示第三栏，再点可收起；窄窗口下位于下方。每次刷新默认收起，已有 MLX 干预仍生效，顶部显示启用组数。要停止干预，请展开并清空干预组。

## 1. 选择模型与适配器

模型列表扫描本地 MLX 配置与 safetensors，以及通过 `runtime.json` 注册的完整 GGUF 文件。仓库不包含任何模型，请先运行 `bash scripts/download.sh`，或通过“模型管理”下载安装。

MLX 后端支持兼容的 `qwen3_5` / `qwen3_5_text` 配置；GGUF 使用 llama.cpp，自动禁用神经元干预、对照和 LoRA。可通过 `brew install llama.cpp` 安装引擎，或设置 `LLAMA_SERVER`。生成上限为 1–4096，上下文预算为 2048、4096、8192；输入与生成上限之和不能超过预算。

LoRA 列表来自 `adapters/<模型ID>/<实验名>/`，要求其中有 `adapters.safetensors` 和 `adapter_config.json`。仓库不附带训练好的适配器。

切换模型会清空当前对话和干预组（有对话时先确认）；切换适配器可保留当前历史，下一轮会使用新的模型／适配器组合。后端只保留一份模型，切换时先释放上一份。

## 2. 不同类型的提示词

- **系统提示词**：定义模型身份、风格、约束。可选通用助手、推理解释、代码调试、写作润色等模板，再手动编辑。
- **用户提示词**：中间输入框里的具体问题，支持多轮追问。
- **前缀／后缀**：展开左侧对应区域，给新问题添加固定文本。例如前缀“请分析以下代码：”，后缀“请指出边界情况”。

前缀、用户文本和后缀用空行连接，形成实际发送的用户消息。历史消息保留当时的内容，不会被新的前后缀重新包裹。

系统提示词的修改会用于下一次请求的整个历史上下文。每一轮下方可以展开“提示词与干预快照”查看当时设置。

## Neuronary 单条配方导入

左侧展开“从 Neuronary 导入配方”，粘贴 `/r/<ID>` 链接并读取预览，再导入所选示例。可设置剂量倍率，来源与原始参数保存在实验快照。当前仅适配网站 `Qwen/Qwen3.5-4B` 到原有 MLX 量化模型；不兼容模型会禁用导入。详细操作和实现差异见 [Neuronary 导入说明](NEURONARY_ZH.md)。

## 3. 手动关闭或增强多个神经元（仅 MLX 模型）

点击层号或“添加组”，每组填写：

| 配置 | 示例 | 含义 |
|---|---|---|
| 层号 | `16` | 从 0 编号，此模型范围 0–31 |
| 通道编号 | `0,1,2,3` | 指定多个通道 |
| 通道区间 | `10-20,100,200-205` | 区间包含两端，允许组合 |
| 倍率 | `0` | 关闭通道 |
| 倍率 | `0.5` | 减弱为一半 |
| 倍率 | `1` | 保持原值 |
| 倍率 | `2` | 放大两倍 |

乘法模式支持 0–4 倍，所有模式合计最多 32 个干预组。Qwen3.5 4B 每层有 9216 个 MLP 中间通道，编号范围 0–9215。可以在不同层配置不同倍率，也可以在同一层设置不同且不重叠的通道组。已启用组之间的重复通道会报错，防止不明确的叠加；同一组内重复编号会去重。

复选框可以临时禁用一组；“清空干预”恢复无干预配置。每轮运行结束、取消或出错后，后端都会恢复原投影模块。不会修改磁盘上的模型权重，也不会训练参数。

干预位置是 **SwiGLU 激活之后、MLP 的 down_proj 输入之前**，不是注意力头或整层隐藏状态。倍率作用于本次完整输入与新生成的所有 token；下一轮会用当时的新设置重新计算历史，不复用上一轮干预的 KV 缓存。

层号着色只表示配置了干预，**不是实时激活值热力图**。放大负激活会使其更负，不等于能力增强。

## 3.1 残差归一化加法

每组新增“干预模式”，可选：

- **乘法缩放**：`激活 × scale`。原有会话没有 mode 字段时仍按乘法处理。
- **归一化加法**：`激活 + delta`，其中 `delta = dose × residual_median / column_norm`。

点击“＋ 添加组”或层号，手动设置层／通道并选择归一化加法，使用滑块或数字框填写 −4 到 +4 的剂量；归一化加法合计最多 128 个通道。也可通过左侧 Neuronary 面板导入配方。发送问题后才会执行。

**加法中的 dose=0 表示不注入；乘法中的 scale=0 才是关闭通道。**负 dose 是向对应权重列方向的反方向注入，不是把神经元关闭。同层同通道不能出现在多个启用组里，即使模式不同；不同通道可以混用两种模式。

### 明确采用的校准约定

原帖没有完整代码。本项目使用下述实现，不声称与作者的隐藏实现完全相同：

1. 用本次完整模板化对话（包含系统提示词、选定历史、当前问题及生成提示标记）做一次**无激活干预**的前向计算，保留当前模型和 LoRA 适配器。
2. 测量目标 decoder 层在残差相加后的输出，即最终 backbone norm 之前的向量，对每个 token 计算 L2 范数。
3. 默认跳过整个序列的第一个 token；分块处理时不会重复跳过每块的首 token。可在“归一化加法：校准约定”中取消跳过选项。
4. 对余下所有 token 的范数取中位数；偶数个样本取中间两个值的平均。
5. MLX 的 `down_proj.weight` 布局为 `[输出维度, 输入通道]`。量化权重先解量化再取第 n 列；加载 LoRA 时把其有效权重更新也计入列范数。
6. 计算各通道的固定 delta，作用于干预分支的**全部输入和全部新生成 token**。校准时跳过首 token，不意味着干预时也跳过它。
7. 每一轮对话重新校准；同一轮生成过程中不更新 delta。校准缓存与生成缓存分离，不复用校准状态。

校准不施加任何乘法或加法组。低精度计算会对实际相加结果进行舍入；4-bit 模型的结果可能与原始精度模型不同。

### 查看实际注入是否生效

回答下方新增“归一化校准”折叠表格，可查看：

- 层号、通道及有符号的 dose；
- 残差范数中位数、有效权重列范数；
- 计算出的 delta；
- 干预分支**首个输入 token**进入 down_proj 前的激活修改前／后值。

这些实测值会随会话一同保存、导出和导入。“已观测实际注入”表示已执行干预分支并采样激活，并不代表获得某种稳定人格。每一轮的量都可能不同；不要将某次 delta 手动当作另一个提示词的固定剂量。

## 4. 多轮对话与对照实验

1. 输入问题，点击“发送并运行”，或按 `⌘/Ctrl + Enter`。
2. 勾选“与无干预结果对照”时，先运行无激活干预分支，再运行当前配置分支。
3. 两个分支使用同一模型、同一适配器、相同历史、温度和随机种子；默认温度为 0。
4. 默认采用“当前配置”的回答进入下一轮上下文。点击另一份回答的“采用此回答继续”，可改用无干预回答。
5. 如果更换早先一轮的答案，需要删除其后对话，界面会先确认。
6. 点击历史问题旁的“编辑并重跑”，在输入框修改后发送。该轮及之后的对话被替换，使用当前控制台设置；发送前可取消编辑。

对照分支都是基于同一条已选历史运行，**不是两条独立累积的聊天会话**。启用 LoRA 时，“无干预”仍包含所选 LoRA，只是不对激活施加缩放。

“新会话”清空历史，但保留模型、提示词和干预设置。需要完全恢复原始计算时，再清空干预并选择不加载适配器。

## 5. 停止、预算与保存

- “停止生成”在下一次可取消的计算边界生效；加载模型或正在执行的 GPU 运算不能被瞬间打断。
- 已停止或失败的回答会显示在页面，但不会加入后续上下文；可编辑该问题后重跑。
- 上下文预算约束“输入 token 数 + 生成上限”，默认 2048，最高 8192。超过预算会明确提示，不会默默截断历史。
- 新生成 token 上限为 1–4096。思考模式也消耗此预算。达到上限时会显示“已到长度上限”。
- 页面显示 token 数和速度；MLX 另显示峰值内存（不是整机内存）。GGUF 不提供该内存指标，显示的平均速率包含预填充时间。不能用极短回答的速度推断长期性能。
- 配置、草稿及已结束的对话自动存入当前浏览器的 localStorage；不同浏览器、端口或 `localhost` / `127.0.0.1` 是不同存储空间。
- “导出实验”保存 JSON，“导入”可恢复配置和完整对话。运行中的半成品不进入导出会话；重要实验建议在完成后导出。导出使用浏览器下载目录，可手动保存到本项目对应的 `outputs/<模型ID>/`。
- 服务端只保留最近 30 个任务的临时状态，没有另存聊天正文；关闭服务会清空这些任务。刷新时如果还有任务在运行，页面可等待或停止该任务，但不会自动恢复尚未完成的对话结果，需重新发送。

## 中英文界面

顶部 **English** 切换到英文，**中文** 切回中文。默认中文；语言选择单独保存在当前浏览器中，刷新仍生效，无需重新启动服务。

切换只更新界面标签、按钮、帮助、模型管理、配方导入与已知状态/错误提示。不会改动当前模型、适配器、采样设置、神经元参数、系统提示词、用户前后缀、草稿或聊天内容，也不会重新发送请求。生成期间可以切换语言。

主动重新选择提示词模板、点击示例问题时，会填入当前语言版本；已经填入的内容不自动翻译。Neuronary 原始描述、备注、示例和模型输出保持原文。未知引擎错误保留原始诊断文字。语言偏好不写入实验导出文件，导入实验不改变语言。浏览器禁止存储时仍可临时切换，但不能保证刷新后保留。

升级后如没有按钮或新资源加载失败，停止旧服务，重新运行 `bash scripts/web.sh` 并刷新页面。正常启动、停止方式不变。
